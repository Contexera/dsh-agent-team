2. Key Technical Concepts:

- **Attention-based delivery model**: `Attention` (not identity) decides whether ordinary updates create unread/wake eligibility. Identity only *establishes* default Attention at specific moments.
- **Two independent Attention faces**: Thread Attention (Member × Thread) and Main stream Attention (Member × Project). The Main stream row is keyed by Member × Project, never given a synthetic Thread ref.
- **Derived vs stored state**: The Human's Main stream Attention is *derived* from `project.createdAtSequence` (never stored); only its read watermark (`humanMainWatermarks`) is stored. Every other Member's row is durable.
- **Replay validation**: `AgentTeamLedger` validates every stored operation against a re-derived expectation on load. Any divergence throws, so a ledger written by an older build fails to open when a newer build changes what a delta must contain.
- **In-memory repairs**: the established pattern (`repairLegacyProjectCleanup`, precedent commit `2980d54`), applied inside `sortedRecords()` — the single replay entry point shared by `replay()` and `validate()`. Never rewrites stored bytes; guards on exact deep-equal so a forgery is not laundered.
- **`inboxDelta` positional parameters** (12 params): `set, removed, addedMarkers, removedMarkers, addedActivityMarkers, removedActivityMarkers, addedMainMarkers, removedMainMarkers, addedReminderMarkers, removedReminderMarkers, setMainAttention, removedMainAttention`.
- **`AgentTeamAttentionSource`** (new): `'thread-author' | 'claim' | 'accountable' | 'project-owner' | 'mention' | 'self'`.
- **`signature` vs `delivered`**: `signature` covers all unread facts; `delivered` covers only what the notice actually rendered. `covered` records `delivered`, so a Thread dropped by the section cap or character budget stays undelivered and retries.
- **Storage layout**: `~/.dsh/storages/agent_team.sqlite`, table `u_agent_team_operations`.
- **Build artifact staleness**: `@contexera/dsh-agent-team/tools` resolves from `node_modules` → root `package.json` `"./tools"` → `packages/tool-agent-team/lib/`, so source changes to the tool surface require `npm run build` before integration tests pass.
- **Typert**: generated Remote artifacts; never hand-edit `packages/agent-team/lib/typert.*`.

    ```ts
    private repairLegacyAttentionSource(operation: AgentTeamOperation, projection: Projection): AgentTeamOperation {
      if (!('inbox' in operation.data)) return operation
      const { inbox } = operation.data
      const threadRows = inbox.attention.set.filter(attention => attention.source === undefined)
      const mainRows = (inbox.mainAttention?.set ?? []).filter(attention => attention.source === undefined)
      if (threadRows.length === 0 && mainRows.length === 0) return operation
      // The cause is derived from the operation, not guessed from a version: the
      // validator re-derives the same row, so a repair that guessed would leave
      // the record failing against it.
      const fallback = this.legacyAttentionSourceOf(operation, projection)
      const withThread = (attention: AgentTeamThreadAttention): AgentTeamThreadAttention => (
        attention.source === undefined ? { ...attention, source: fallback } : attention)
      const withMain = (attention: AgentTeamMainAttention): AgentTeamMainAttention => (
        attention.source === undefined ? { ...attention, source: fallback } : attention)
      const repaired = {
        ...inbox,
        attention: { ...inbox.attention, set: inbox.attention.set.map(withThread) },
        ...(inbox.mainAttention === undefined ? {} : { mainAttention: { ...inbox.mainAttention, set: inbox.mainAttention.set.map(withMain) } }),
      }
      return { ...operation, data: { ...operation.data, inbox: repaired } } as typeof operation
    }

    private legacyAttentionSourceOf(operation: AgentTeamOperation, projection: Projection): AgentTeamAttentionSource {
      switch (operation.kind) {
        case 'team/project-owner-added': return 'project-owner'
        case 'team/claim-created': return 'claim'
        case 'team/task-changed': return 'accountable'
        case 'team/message-sent':
        case 'team/thread-replied':
          return projection.rulesVersion >= 2 ? 'self' : 'mention'
        case 'team/thread-attention-changed':
        case 'team/main-attention-changed': return 'self'
        case 'team/thread-started': return 'thread-author'
        case 'team/task-accountable-changed': return 'accountable'
        default: return 'self'
      }
    }
    ```
