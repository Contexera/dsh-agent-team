2. Key Technical Concepts:

- **Two-level delivery model (old)**: `immediate` vs `threshold`; threshold = 5 undelivered ordinary facts per Member × Thread.
- **The root cause**: `isThresholdFact(entry, owner)` in `inbox-delivery.ts` consulted only the `owner` boolean, so follow/unfollow had no effect on an owner's delivery class.
- **Target model**: Attention (follow/unfollow) decides both "is there unread" and "how fast am I notified"; identity only establishes *default* Attention; responsibility events and reminders bypass Attention entirely.
- **Three collaboration signals**: ordinary progress (requires Attention), direct summons (@ / reply, no Attention needed), responsibility signals (Task assignment / review / transfer / reminder, cannot be unsubscribed).
- **Main stream Attention**: a new `(memberId, projectRef)` row — deliberately NOT a synthetic Thread ref, which would pollute Thread indexes.
- **Human's Main attention is derived, not stored**: starts at `project.createdAtSequence`; only the read watermark (`humanMainWatermarks`) is persisted. This preserved the "Human identity is constant and never stored" principle and avoided changing `team/project-created`'s stored shape.
- **Agent owner grant** atomically writes `startMainAttention(memberId, projectRef, sequence)` — starts at the grant, inherits no backlog.
- **Withdrawing ownership ≠ unfollow** (Attention kept); **leaving Workspace / removal / archival DO end it**.
- **`covered` signature** (process memory) is what now alone prevents duplicate wakes after threshold removal.
- **Notice coalescing**: `removeExpectedTeamWake` replaces a queued-but-unread notice rather than stacking.
- **New operation kind** `team/main-attention-changed` requiring: zod schema, replay validation, protocol test row, `changeScopesOf`, `touchedThreadRefs`.
- **Single-writer ledger queue** (`enqueue`): non-reentrant — calling one `enqueue`d public method from inside another deadlocks.
- **Build artifact staleness**: the `team-member` preset resolves `@contexera/dsh-agent-team/tools` from `node_modules` → `lib/`, so tool-surface changes need `npm run build` before member-lifecycle tests pass.
- **Core skill budget**: 7850 chars (dsh-developer's 8000 active-set limit minus 150 margin), counted over the whole skill directory including `references/`.
- **Doc block ceilings** enforced by `scripts/check-docs.mjs`.

- **`packages/agent-team/src/inbox-delivery.ts`** (rewritten for ticket 01) — the core delivery decision, now a single class:
```ts
export type InboxDelivery = 'immediate'
export type InboxScopeRole = 'owner' | 'follower' | 'member'

export interface InboxDeliveryInput {
  readonly threads: readonly InboxThreadUnread[]
  readonly main: readonly InboxMainUnread[]
  /** Signature of the immediate facts the last delivery attempt answered. */
  readonly covered: string | undefined
}

export interface InboxThreadPlan {
  readonly threadRef: AgentTeamThreadRef
  readonly role: InboxScopeRole
  readonly delivery: InboxDelivery
}

export interface InboxDeliveryPlan {
  readonly trigger: InboxDelivery | undefined
  readonly signature: string
  readonly threads: readonly InboxThreadPlan[]
}

export function planInboxDelivery(input: InboxDeliveryInput): InboxDeliveryPlan {
  const immediate: (string | number)[][] = []
  const threads: InboxThreadPlan[] = []
  for (const { item, facts, reminders = [] } of input.threads) {
    const threadRef = item.thread.threadRef
    if (reminders.length > 0) immediate.push([threadRef, 'reminder', ...reminders.map(reminder => `${reminder.kind}:${reminder.baselineSequence}`)])
    const now = facts.map(entry => entry.fact.sequence)
    if (now.length > 0) immediate.push([threadRef, ...now])
    threads.push(Object.freeze({ threadRef, role: item.attention === undefined ? 'member' : 'follower', delivery: 'immediate' as const }))
  }
  for (const { projectRef, entries } of input.main) {
    if (entries.length > 0) immediate.push([projectRef, ...entries.map(entry => entry.sequence)])
  }
  const signature = immediate.length === 0 ? '' : JSON.stringify(immediate)
  const trigger = signature !== '' && signature !== input.covered ? 'immediate' : undefined
  return Object.freeze({ trigger, signature, threads: Object.freeze(threads) })
}
```
