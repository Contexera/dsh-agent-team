# Team Member 工具面控制权

- **状态**：本轮完成，2026-10-23 归档。用户接受当前工具拦截与提示不隔离的边界；未修改 Harness。
- **最后核对**：2026-10-23。
- **当前边界**：Team mode 过滤其他官方或自定义插件注入的未声明工具，并拒绝直接和嵌套调用；不拦截其他插件注入的 prompt，也不因提示冲突阻止 Member 对话。现有公开接口不支持完整的 Member 提示隔离，必需上下文可在组装后被恢复。
- **完成情况**：默认 preset 工具限制、能力缩减、同名替换检查及执行拦截已落实。真实官方插件先加载、后加载和保持启用时的 Member 暂停/恢复均能完成对话；普通 Agent 保留官方能力。相关测试 112 项、类型检查和 Host 构建通过。本次文档收尾只运行文档与差异检查。
- **正式文档出口**：[Tools and preset](../../../../docs/architecture/tools-and-preset.md) 及其中文版本定义现行行为与限制；[CHANGELOG](../../../../CHANGELOG.md) 说明同时启用其他插件时只拦截未声明工具，不过滤其提示。

## 归档范围

本轮不继续扩大隔离实现，不修改上游，不新增通用策略框架。未实施的三张上游改造、封闭策略接入与完整双 Team 共存验收 tickets 已关闭并移除；其设计背景保留在调研材料中，不构成本轮剩余任务。
