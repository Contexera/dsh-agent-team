# 08 — 回复回执只处理原讨论和原草稿

**What to build:** 在同一个侧栏从正在发送回复的讨论 A 切到 B，A 的回复仍由 Host 决定是否提交；B 可以照常编辑和发送，A 的结果不会改动 B 的草稿、附件、消息或报错。确认提交只清掉发送时那份未改动的草稿。完全关闭再打开时的重复发送另见 [12](12-reply-reopen-before-receipt.md)。
**Blocked by:** 07（已完成）
**Status:** complete

- [x] 延迟 A 的成功与失败，验证 B 可以开始自己的发送，A 不改变 B 的输入、消息、报错和发送状态。
- [x] 同一侧栏 A → B → A 时，原回复仍在途，无法再次发送；完全关闭重开后编辑的新草稿不会被旧回执清除。
- [x] 正常发送、打开期间的重试、附件流程和失败保留草稿继续通过。
