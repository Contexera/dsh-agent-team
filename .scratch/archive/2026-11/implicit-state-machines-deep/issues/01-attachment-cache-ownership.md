# 01 — 附件内容的提交顺序与过期回收

**What to build:** 同一个请求的上传或带文件发送同时到达时，只接受一份内容；重试不覆盖或清除已提交 Message 的副本。Host 清理过期且没有被引用的半写附件。
**Blocked by:** None — can start immediately
**Status:** complete

- [x] 并发上传同一请求 ID、不同内容，拒绝冲突；相同内容仍重放原结果。
- [x] 并发发送的同名、同大小但不同内容文件不能改写首次接受的附件；已提交 Message 引用的字节保持可读。
- [x] 过期的无 metadata 或 metadata 损坏的孤立目录可回收；新条目、已引用半写条目、外来目录和符号链接保留。
- [x] 暂停发送在 ledger 提交前，启动清理再放行提交；已上传文件和路径副本都按最新引用判断，成功发送后仍可读。
- [x] 回归先失败后通过；现有重启重试、读取错误分类和保留期测试通过。
