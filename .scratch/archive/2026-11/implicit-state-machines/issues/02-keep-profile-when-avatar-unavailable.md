# 02 — 头像读取失败时仍显示 Human 身份

**What to build:** Human 的资料已经读到，但头像请求失败时，Team 页面仍显示姓名和文字头像；头像请求恢复后，重新加载页面可读到图片。

**Blocked by:** 无。

**Status:** complete

- [x] 从实际身份读取入口让资料请求成功，分别让头像 Remote 返回错误和读取调用抛异常，覆盖首次读取和之后的刷新（头像引用切到尚未加载的新值）；确认没有一直加载或未处理的异常。Harness 通常把网络失败转为 Remote 错误，不能用独立 loader 抛错替代实际入口验收。
- [x] 若复现，头像降级不丢姓名，不将失败结果当成已缓存的头像；同一头像引用在下次身份刷新可重试，并用重新加载页面验证。设置页现有重试按钮针对资料读取失败，本票不要求给头像新增按钮。单独的资料请求失败仍按现有方式保留旧值或提示重试。
- [x] 若修改可见表现，按 [Web 验收要求](../spec.md#范围与决策) 检查 Team 页面与设置入口。

验收：挂载的 Team Client 在头像 Remote 拒绝或抛异常后仍显示姓名和首字；切换到未缓存的新引用时，旧图不会替代新图。同一引用再次读取、重新挂载 Client 都能恢复。
