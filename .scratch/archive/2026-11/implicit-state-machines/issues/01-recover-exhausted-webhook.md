# 01 — 重启后仍可重放已耗尽重试的 Webhook

**What to build:** 已返回 `202` 的 Webhook 在重试耗尽后，即使写失败记录或删除待处理记录时中断，重启后 Project 负责人仍能找到同一次投递并手动重放。

**Blocked by:** 无。

**Status:** complete

本票完成的是投递恢复行为。发布前还需通过 [08 的存储版本升级验收](08-version-webhook-settlement-storage.md)。

- [x] 分别拒绝写入失败记录、拒绝删除接收记录，用新 Host 打开同一份存储。恢复后只留一个可重放的结果，不再自动跑已经记录为耗尽的脚本。
- [x] 暂停中的订阅可完成上述清理，恢复订阅后仍可手动重放；重放脚本收到原投递标识和原请求内容。
- [x] 原有 1、5、30 分钟重试、正常耗尽、成功结果去重、删除及归档路径的回归继续通过。维护文档写明恢复保证。
