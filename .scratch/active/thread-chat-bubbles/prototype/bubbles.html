这份原型要确认的规则

  • 左右归属：人类（我）的消息靠右、业务色浅底；Agent 成员靠左、中性底。系统命名上用「我方 / 对方」，不写死「Human」。
  • 「有人@我」是标记而非重新分组：一条 Agent 消息即便 @ 了我，它仍然靠左、仍然属于那位 Agent。标记是一条独立的信息，用主题色描边 + 气泡内右上角的徽标表达，不用位置暗示。
  • 徽标位置：气泡内部第一行、右对齐（margin-left:auto），正文在其下方开始。标记不占用发送者昵称行的位置，也不改变气泡的圆角与归属。
  • 判定依据：该条消息的结构化 mentions 含 member:human，即 Host 认定的投递事实，不靠正则扫正文。
  • 折叠：超过 600 字默认裁切 + 渐隐 + 「展开」文字链接，沿用现有 600 字规则。
  • 非气泡行：Activity（认领/接受/关闭）、日期分隔、未读分界保持现有形态，不套气泡——它们是时间线事实，不是某人的发言。
