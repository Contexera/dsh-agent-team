# 01 — 在 Team 设置放行和撤销宿主工具

**What to build:** 用户在当前 DSH profile 的 Team 设置中搜索、多选已注册的宿主全局工具并保存。所有 Team 成员从原会话的下一轮开始使用新清单，无需重启。

**Blocked by:** None — can start immediately

**Status:** ready

- [ ] 清单默认空，可按确切工具名搜索、多选和保存；已选但未注册的名称仍可见、可移除。已有成员工具不会重复列出，外部同名工具不能替换内置定义。不安装或重新挂载插件，不根据工具名推断插件来源。
- [ ] profile 持久化一份统一清单。已选外部工具适用于所有 Team 成员，包括已有工具白名单的成员；旧白名单仍限制原有工具，不能授权清单外工具。普通 DSH 会话继续使用自己的工具清单。
- [ ] 在同一会话用真实 DSH 插件和模拟模型验证默认隔离、放行后可调用、撤销后不可声明及不可直接或嵌套调用。运行中的回合继续使用原配置，下一轮第一条请求使用新配置，覆盖连续两轮之间不空闲。工具列表由 DSH 正常更新，不额外注入提示、不唤醒成员。
- [ ] 原工具的激活条件和权限仍生效。插件卸载或同名重注册不接管已准备的步骤，成员 scope 的同名注册不能冒充已放行的宿主工具。更新失败报告原因，不放宽原有工具范围，也不在下一轮沿用已撤销的外部授权。
- [ ] 用组装后的 Web 验证搜索、多选、保存、取消改动、空清单、缺失工具和保存失败，检查桌面、窄屏和键盘操作。更新用户配置说明和工具范围文档，注明此设置不影响插件原有提示注入。
