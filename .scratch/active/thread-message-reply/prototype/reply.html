这份原型要确认的规则

  • 选择哪条：每条消息的昵称行尾部有一个 回复 操作（28px 高，与 shipped 消息操作条同规格）。
  • 操作条的显隐：整体包在 @media (hover: hover) 里 —— 只有真有 hover 的设备才隐藏，触屏常显。隐藏时靠 :hover 与 :focus-within 两个条件显示，所以键盘 Tab 也能到达，不会变成「只有鼠标能用」。
  • 正在回复哪条：被回复的消息加一圈描边（不是换底色），composer 顶部出现引用条，可随时取消。
  • 引用块的形态：作者 + 正文摘要，一行截断；点击跳到原文并短暂闪烁。长原文不会被重贴一遍。
  • 同人续行：昵称行隐藏时，操作条仍随 hover 出现在同一行的尾部，不占额外高度。

需要你裁决 4 件事（见 spec.md）

  • O1：Channel 页要不要也能回复？（Thread 独有 / 进 Thread 回复 / 顶层也能互相引用）
  • O2：回复是否自动通知原文作者？还是只有写 @作者 才通知？
  • O3：引用只存 messageRef 由 Host 解析，还是同时存一份正文快照？
  • O4：引用块要不要左侧竖线？（当前有竖线；「有人@我」已改成描边 + 徽标，需确认是否保持一致）
