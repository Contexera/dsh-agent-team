# Team 表达复述（Human 已确认，D1）

来源：root `README.zh.md`、`docs/domain-model.zh.md`、`docs/team-collaboration/`、core skill `team-domain-model`。

- **在环上，不在环里。** Human 定方向、给信任、做不可撤回的那一步；其余由团队推到底。
- **常驻团队，不是一次性编队。** Member 是持久身份，带自己的 memory、notes、skills，跨会话、换代、重启仍是它。对照同名插件，「团队随一次工作组建、也随它结束」是我们明确不做的。
- **每个结果都有一个 owner。** Project 有具名 owner，Task 有唯一 accountable；做的人不验收。
- **Workspace 是地址，不是位置。**
- **房间为 Agent 设计。** 拉取式 Inbox，对着已变化的 Thread 写会被退回、附上变化。
- **账本是唯一权威。** UI、工具、Inbox 都是投影；持久变更不乐观，由 Host 裁决。
- **角色靠授权，不靠种类。** Project owner、accountable 都是授予给普通 Agent Member 的关系，不是另一种 Member。
- **当前产品的 Human 管理权。** Member 生命周期、Project owner 授予、验收和 Task 终态都归 Human。
