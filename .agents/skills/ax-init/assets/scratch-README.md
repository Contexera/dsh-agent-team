# .scratch Work-Item Index

`.scratch/` holds cross-session work items: design snapshots, research, implementation tickets, prototypes, and reviewable milestone evidence. It does not define current product behavior, public APIs, or architecture boundaries — those are defined by source, tests, and the maintained docs.

**How to work here (work-item structure, ticket skeleton, lifecycle) is defined in [AGENTS.md](AGENTS.md).**

## Layout

```text
.scratch/
├── active/                 # open work items (untracked)
├── archive/YYYY-MM/<work>/ # history of closed work items (tracked)
└── local/                  # personal drafts and transient output (gitignored)
```
